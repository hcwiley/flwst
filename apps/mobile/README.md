# @flwst/mobile

React Native (Expo) application for FlowState.

## Setup

This package needs to be initialized with Expo. Run the following command from
the repo root:

```bash
cd apps/mobile
npx create-expo-app@latest . --template blank-typescript
```

Or if you prefer to initialize manually:

```bash
cd apps/mobile
npx expo init . --template blank-typescript
```

## Development

After initialization:

```bash
pnpm dev
```

## Notes

- Uses Expo SDK ~52.0.0
- ESM module system
- Phase 1: Stub only, minimal implementation
